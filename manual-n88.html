N88互換BASIC マニュアル

NEC の PC-8801 / PC-9801 シリーズ向けBASICの文法を参考にした、非公式の互換実装です。行番号つきの手軽な書き方に、色・図形・音・文字列処理がそろった、日本のパソコン黎明期の定番です。

N88互換BASIC とは

N88互換BASIC が参考にしている N88-BASIC は、NEC のパソコン PC-8801 シリーズ(のちに PC-9801 シリーズ)に搭載された BASIC で、マイクロソフト社の BASIC を元にしています。このシミュレータは、その文法や使い方を参考に独自に作った非公式の互換実装で、NEC やマイクロソフト社とは関係がありません。行番号で書くスタイルは Tiny BASIC と同じですが、変数の型、配列、文字列、FOR/WHILE、ON GOTO、DATA/READ、グラフィック命令などが加わっています。

このシミュレータの N88互換BASIC は、よく使われる命令を中心に再現した学習用のものです(実機のソフトウェアや画像は含みません)。ディスクやカセットの命令、スプライト、PEEK/POKE などの機種依存の機能は含みません。

画面とはじめかた

  • 文字は 80桁 × 25行(WIDTH 40,25 で40桁)。グラフィックは 640 × 400 ドット、8色で、文字の下に重なって表示されます。
  • 全角文字(日本語)は2桁ぶんを使います。
  • 実行は 「▶ 実行」(Ctrl+Enter)。INPUT の入力は画面下の入力欄に打ち込んで Enter。
  • INKEY$ でキー入力を読むときは、画面をクリックしてからキーを押します。
  • すべての行は行番号で始めます(「行番号をふる」ボタンで自動で付けられます)。

プログラムの書き方

  • 各行は 行番号 で始めます。実行は番号の小さい順で、入力順は関係ありません。
  • 1行に複数の文を書くときは : で区切ります(10 A=1:B=2:PRINT A+B)。
  • コメントは REM か '(アポストロフィ)。' は文の途中からでも書けます。
  • 大文字・小文字は区別されません。? は PRINT の省略形です。
  • ブロックの IF…END IF はありません。IF 条件 THEN 文 ELSE 文 を1行で書きます。

変数・型・演算子

変数と型

変数名は英字で始まる英数字(長さは自由)。名前の最後の記号で型が決まります。

型記号例説明
単精度実数! (省略可)A X!標準の型。表示は7桁まで。
倍精度実数#PI#桁数の多い実数(表示は同じ規則)。
整数%N%-32768〜32767。代入のとき四捨五入されます。
文字列$A$ NAME$文字の並び。"..." で書きます。

DEFINT A-Z のように宣言すると、記号なしの変数もその型になります。型が合わない代入(A$=5 など)は「型が一致しません」エラーです。

配列

DIM A(10) で A(0)〜A(10) の11個。DIM B(3,3) のように多次元も可能です。宣言なしで使うと、各次元 0〜10 の配列が自動で作られます。OPTION BASE 1 で添字を1から始められます。

ファイル

データをファイルに保存して、あとで読み込めます。ファイルはお使いのブラウザの中(このサイト用の保存領域)に保存されるので、ページを閉じても残ります。別のパソコンや別のブラウザとは共有されません(ブラウザのサイトデータを消すと一緒に消えます)。

  • ファイル名は英数字と _ - . で32文字まで(大文字小文字は区別しません)。"A:DATA.DAT" のようなドライブ名は書いても無視されます。
  • ファイル番号は #1〜#15。同時に開けるのは別々の番号・別々のファイルです。
  • プログラムが終了(END・エラー・停止)すると、開いているファイルは自動で閉じて保存されます。(実機のように CLOSE を忘れて失う心配はありません。それでも CLOSE を書く習慣をつけましょう。)

順番に読み書きする(シーケンシャルファイル)

DATAが足りません (Out of DATA)4READ の数が DATA より多い。
不正な関数呼び出しです (Illegal function call)5関数の引数の範囲が不正(SQR(-1) など)。
オーバーフロー (Overflow)6数が大きすぎる / 整数変数の範囲(-32768〜32767)を超えた。
未定義の行番号です8GOTO などで存在しない行を指定した。
添字が範囲外です (Subscript out of range)9配列の範囲を超えた。
0で割りました (Division by zero)110 で割った。
型が一致しません (Type mismatch)13文字列と数を混ぜた。
行番号がありません2行番号のない行がある。

エラーが起きるとプログラムは止まり、エラー内容と行番号が表示され、エディタの該当行が選択されます。ON ERROR GOTO で自分で処理することもできます。

制限事項

  • プログラム自体の SAVE/LOAD/MERGE(エディタの「保存」「読み込み」を使ってください)、PEEK/POKE、OUT/INP、スプライト、GET@/PUT@(図形の取り込み)、VIEW/WINDOW、KEY・割り込み(ON KEY/ON TIMER)は未対応です。KEY と CONSOLE は書いても何も起きません。
  • ファイルはブラウザの中に保存されます。ディスクやカセットなどの装置名は無視され、LOF や LOC の値は実機と少し違います。ランダムファイルの文字列は、日本語も1文字を1つと数えます。
  • グラフィックは 640 × 400 ドット・8色固定で、文字層とグラフィック層は別です。CLS は両方を消します。
  • 単精度/倍精度の違いは表示桁数にだけ現れ、内部では倍精度で計算します(PRINT 1/3 は .3333333)。
  • キーワードの途中に空白がなくても読める「FORI=1TO10」のような書き方は、キーワードの前後に空白が必要です。
  • 音は Web Audio による簡易再生です。PLAY は同時に1音ずつです。
