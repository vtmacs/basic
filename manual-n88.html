N88-BASIC マニュアル

NEC PC-8801 / PC-9801 シリーズの標準BASIC。行番号つきの手軽な書き方に、色・図形・音・文字列処理がそろった、日本のパソコン黎明期の定番です。

N88-BASIC とは

N88-BASIC は NEC のパソコン PC-8801 シリーズ(のちに PC-9801 の N88-BASIC(86) も)に搭載された BASIC で、マイクロソフトの BASIC を元にしています。行番号で書くスタイルは Tiny BASIC と同じですが、変数の型、配列、文字列、FOR/WHILE、ON GOTO、DATA/READ、グラフィック命令などが加わっています。

このシミュレータの N88-BASIC は、よく使われる命令を中心に再現した学習用のものです。ディスクやカセットの命令、スプライト、PEEK/POKE などの機種依存の機能は含みません。

画面とはじめかた

  • 文字は 80桁 × 25行(WIDTH 40,25 で40桁)。グラフィックは 640 × 400 ドット、8色で、文字の下に重なって表示されます。
  • 全角文字(日本語)は2桁ぶんを使います。
  • 実行は 「▶ 実行」(Ctrl+Enter)。INPUT の入力は画面下の入力欄に打ち込んで Enter。
  • INKEY$ でキー入力を読むときは、画面をクリックしてからキーを押します。
  • すべての行は行番号で始めます(「行番号をふる」ボタンで自動で付けられます)。
Hello, Worldシミュレータで試す ▶
10 CLS
20 PRINT "Hello, World!"
30 PRINT "こんにちは N88-BASIC"
40 END

プログラムの書き方

  • 各行は 行番号 で始めます。実行は番号の小さい順で、入力順は関係ありません。
  • 1行に複数の文を書くときは : で区切ります(10 A=1:B=2:PRINT A+B)。
  • コメントは REM か '(アポストロフィ)。' は文の途中からでも書けます。
  • 大文字・小文字は区別されません。? は PRINT の省略形です。
  • ブロックの IF…END IF はありません。IF 条件 THEN 文 ELSE 文 を1行で書きます。

変数・型・演算子

変数と型

変数名は英字で始まる英数字(長さは自由)。名前の最後の記号で型が決まります。

型記号例説明
単精度実数! (省略可)A X!標準の型。表示は7桁まで。
倍精度実数#PI#桁数の多い実数(表示は同じ規則)。
整数%N%-32768〜32767。代入のとき四捨五入されます。
文字列$A$ NAME$文字の並び。"..." で書きます。

DEFINT A-Z のように宣言すると、記号なしの変数もその型になります。型が合わない代入(A$=5 など)は「型が一致しません」エラーです。

配列

DIM A(10) で A(0)〜A(10) の11個。DIM B(3,3) のように多次元も可能です。宣言なしで使うと、各次元 0〜10 の配列が自動で作られます。OPTION BASE 1 で添字を1から始められます。

演算子(強さの順)

演算子意味
^べき乗(2^10 = 1024)
- (単項)符号
* /かけ算・割り算
\整数の割り算(7\2 = 3)
MOD余り(7 MOD 3 = 1)
+ -足し算・引き算(+ は文字列の連結にも使う)
= <> < > <= >=比較。真は -1、偽は 0。文字列は辞書順で比較
NOTビット反転(NOT 0 = -1)
ANDビットごとの論理積
OR XOR EQV IMP論理和・排他的論理和・同値・包含

16進数は &HFF、8進数は &O17、2進数は &B101 と書けます。

演算子シミュレータで試す ▶
10 PRINT 7/2;7\2;7 MOD 3;2^10
20 PRINT (3>2);(2>3);(5 AND 3);(5 OR 2)
30 A$="ABC"+"DEF": PRINT A$
40 PRINT &HFF;&B101
50 END

制御の命令

命令書式説明
IFIF 条件 THEN 文 [ELSE 文]条件が真(0以外)のとき THEN の文を、そうでなければ ELSE の文を実行。THEN の後に行番号だけを書くと、その行へ飛びます。
GOTOGOTO 行番号指定の行へ飛びます。
GOSUB / RETURNGOSUB 行番号 … RETURNサブルーチンを呼び出して戻ります。
ON … GOTO / GOSUBON 式 GOTO 行1,行2,…式の値が 1 なら行1、2 なら行2…へ飛びます。範囲外なら次の文へ。
FOR / NEXTFOR 変数=初期値 TO 終了値 [STEP 増分] … NEXT [変数]決まった回数のくり返し。NEXT J,I のように複数を閉じることもできます。
WHILE / WENDWHILE 条件 … WEND条件が真の間くり返し。
END / STOPENDプログラムを終了します。
ON ERROR GOTOON ERROR GOTO 行番号エラーが起きたとき、その行へ飛びます(0 で解除)。
RESUMERESUME [NEXT | 行番号]エラー処理から戻ります。そのまま RESUME でやり直し、NEXT で次の文から。
ERR / ERLERR ERL直前のエラーの番号と、エラーの起きた行番号。
IF / FOR / WHILEシミュレータで試す ▶
10 FOR I=1 TO 15
20   IF I MOD 15=0 THEN PRINT "FizzBuzz" ELSE IF I MOD 3=0 THEN PRINT "Fizz" ELSE IF I MOD 5=0 THEN PRINT "Buzz" ELSE PRINT I
30 NEXT I
40 N=0
50 WHILE N<3
60   N=N+1: PRINT "N=";N
70 WEND
80 END

グラフィック

座標は左上が (0,0)で、右へ x、下へ y が増えます(640 × 400)。色は色番号(0〜7)。色を省略すると COLOR で決めた色になります。

命令書式説明
PSETPSET (x,y)[,色]点を打ちます。PSET STEP(dx,dy) で直前の位置からの相対位置。
PRESETPRESET (x,y)点を背景色で消します。
LINELINE [(x1,y1)]-(x2,y2)[,色[,B|BF]]線。B で四角形の枠、BF で塗りつぶした四角形。始点を省略すると直前の位置から。
CIRCLECIRCLE (x,y),半径[,色[,開始角,終了角[,比率]]]円・円弧・楕円。角度はラジアン(右が0、反時計回り)。比率が1より小さいと横長の楕円。角度に負の符号を付けると中心への線も引きます。
PAINTPAINT (x,y)[,塗り色[,境界色]](x,y) をふくむ閉じた領域を塗ります。境界色を指定した場合は、その色の線まで塗ります。
POINTPOINT(x,y)(x,y) の色番号を返す関数。

メッセージ番号原因

エラーが起きるとプログラムは止まり、エラー内容と行番号が表示され、エディタの該当行が選択されます。ON ERROR GOTO で自分で処理することもできます。

制限事項

  • ファイル(OPEN/CLOSE/SAVE/LOAD)、PEEK/POKE、OUT/INP、スプライト、GET/PUT@(図形の取り込み)、VIEW/WINDOW、KEY・割り込み(ON KEY/ON TIMER)は未対応です。KEY と CONSOLE は書いても何も起きません。
  • グラフィックは 640 × 400 ドット・8色固定で、文字層とグラフィック層は別です。CLS は両方を消します。
  • 単精度/倍精度の違いは表示桁数にだけ現れ、内部では倍精度で計算します(PRINT 1/3 は .3333333)。
  • キーワードの途中に空白がなくても読める「FORI=1TO10」のような書き方は、キーワードの前後に空白が必要です。
  • 音は Web Audio による簡易再生です。PLAY は同時に1音ずつです。
