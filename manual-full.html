Full BASIC マニュアル

JIS X 3003 / ISO 10279 で標準化された構造化BASIC。行番号なしで、IF…END IF・SELECT CASE・DO…LOOP・SUB / FUNCTION を使ってスッキリ書けます。

Full BASIC とは

Full BASIC は、各社バラバラだったBASICを整理するために国際規格(ANSI/ISO)と日本工業規格(JIS)として定められた BASIC です。構造化プログラミング(ブロックを使って見通しよく書く)を前提にしていて、行番号に頼らずに書けるのが大きな特徴です。日本では教育用に使われてきました。

このシミュレータでは、規格にある基本構文と、グラフィックス(SET WINDOW・PLOT・BOX)を中心に再現しています。

規格の Full BASIC では行番号が必須ですが、このシミュレータでは行番号は省略できます。

行番号を1つも書かなかったときは、プログラムの上から数えた番号(コメント行も数え、空行は数えません)が自動で付きます。この番号が GOTO / GOSUB の飛び先になり、エラーの場所の表示にも使われます。画面左の「行番号つきリスト」で確認できます。自分で行番号を書いたときは、その番号が使われます。

自動の行番号と GOTOシミュレータで試す ▶
! コメントの行も数えるので、この行が1番、LET n = 1 が2番、PRINT n が3番
LET n = 1
PRINT n
LET n = n + 1
IF n <= 3 THEN GOTO 3
END

画面とはじめかた

  • 画面は正方形の 400 × 400 ドットのグラフィック面と、50桁 × 25行の文字画面です(白い紙のような見た目)。
  • 実行は 「▶ 実行」(Ctrl+Enter)。INPUT の入力は画面下の入力欄から。
  • 変数や命令は大文字・小文字を区別しません。変数名は英字で始まる英数字と _、文字列変数は末尾に $ を付けます。
Hello, Worldシミュレータで試す ▶
! はじめての Full BASIC
PRINT "Hello, World!"
PRINT "こんにちは Full BASIC"
END

プログラムの書き方

  • 1行に1つの文が基本です。複数書くときは : で区切ります(LET a = 1 : LET b = 2)。
  • コメントは ! から行末まで、または REM。
  • 変数への代入は LET 変数 = 式。LET は省略もできます。
  • 文字列の連結は &(+ でも連結できます)。
  • サブプログラム(SUB / FUNCTION)は、メインの END のあとに書くのが普通です。メインとして実行される途中にあっても、呼び出されるまで実行されません。
代入と文字列シミュレータで試す ▶
LET a = 3
LET b$ = "abc"
LET c$ = b$ & "def"
PRINT a * 2; c$      ! コメント
END

   IF MOD(i, 15) = 0 THEN

SELECT CASEシミュレータで試す ▶
FOR score = 40 TO 100 STEP 15
   SELECT CASE score
   CASE IS >= 90
      LET g$ = "A"
   CASE 70 TO 89
      LET g$ = "B"
   CASE 50, 60
      LET g$ = "C"
   CASE ELSE
      LET g$ = "D"
   END SELECT
   PRINT score; " -> "; g$
NEXT score
END
DO WHILE(コラッツ予想)シミュレータで試す ▶
LET n = 100
LET count = 0
DO WHILE n > 1
   IF MOD(n, 2) = 0 THEN
      LET n = n / 2
   ELSE
      LET n = 3 * n + 1
   END IF
   LET count = count + 1
LOOP
PRINT "ステップ数 ="; count
END

サブプログラム(SUB / FUNCTION)

  • SUB 名前(仮引数, …) … END SUB は CALL 名前(実引数, …) で呼び出します。
  • FUNCTION 名前(仮引数, …) … END FUNCTION は式の中から呼び出せます。関数の値は、関数名に代入します(LET 名前 = 値)。
  • 引数に変数だけを渡すと、SUB の中での変更が呼び出し元に反映されます(参照渡し)。式を渡したときは値だけが渡されます。
  • 配列は仮引数に a() と書いて渡せます。
  • サブプログラムの内部は独立していて、外側の変数は見えません。必要な値は引数で渡します。再帰呼び出しもできます。
  • EXIT SUB / EXIT FUNCTION でその場で戻ります。DEF 名前(仮引数) = 式 で1行の関数も定義できます。
FUNCTION / SUB / DEFシミュレータで試す ▶
PRINT "5! ="; fact(5)
PRINT "半径2の円の面積 ="; area(2)
LET a = 10
LET b = 20
CALL swap(a, b)
PRINT "a ="; a; " b ="; b
END

FUNCTION fact(n)
   IF n <= 1 THEN
      LET fact = 1
   ELSE
      LET fact = n * fact(n - 1)
   END IF
END FUNCTION

DEF area(r) = PI * r ^ 2

SUB swap(x, y)
   LET t = x
   LET x = y
   LET y = t
END SUB

グラフィック

Full BASIC のグラフィックは、まず SET WINDOW で自分の好きな座標系を決めてから描きます。座標は数学と同じ向き(右が x、上が y)で、画面全体(正方形)が窓になります。窓を決めないと (0,0)〜(1,1) になります。

命令書式説明
SET WINDOWSET WINDOW 左, 右, 下, 上座標系を決めます。SET WINDOW -5, 5, -5, 5 なら中心が (0,0)。
SET COLORSET COLOR 色描く色。0〜7、色名("RED")、MIX(r,g,b)。
PLOT POINTSPLOT POINTS: x,y; x,y; …点を打ちます。
PLOT LINESPLOT LINES: x,y; x,y; …点を順につないだ折れ線を描きます。
PLOT AREAPLOT AREA: x,y; x,y; …多角形を塗りつぶします。
PLOT TEXTPLOT TEXT, AT x,y: "文字"図形画面に文字を描きます。
BOX LINESBOX LINES 左, 右, 下, 上四角形の枠。
BOX AREABOX AREA 左, 右, 下, 上塗りつぶした四角形。
BOX CIRCLE / ELLIPSEBOX CIRCLE 左, 右, 下, 上四角形にぴったり入る円・楕円の枠。
BOX DISKBOX DISK 左, 右, 下, 上塗りつぶした円・楕円(このシミュレータの拡張)。
CLEARCLEAR画面を消します。
色01234567
番号黒青赤紫緑水色黄白
色名"BLACK""BLUE""RED""MAGENTA""GREEN""CYAN""YELLOW""WHITE"

MIX(r,g,b) は赤・緑・青の割合(0〜1)で色を作ります(MIX(1,0.5,0) はオレンジ)。

グラフシミュレータで試す ▶
SET WINDOW -7, 7, -1.5, 1.5
SET COLOR "BLUE"
PLOT LINES: -7, 0; 7, 0
PLOT LINES: 0, -1.5; 0, 1.5
SET COLOR "RED"
FOR x = -6.5 TO 6.5 STEP 0.05
   PLOT LINES: x, SIN(x); x + 0.05, SIN(x + 0.05)
NEXT x
END
図形シミュレータで試す ▶
SET WINDOW 0, 10, 0, 10
SET COLOR "YELLOW"
BOX AREA 1, 4, 1, 4
SET COLOR "RED"
BOX LINES 1, 4, 1, 4
SET COLOR "BLUE"
BOX CIRCLE 5, 9, 1, 5
SET COLOR "GREEN"

PLOT TEXT, AT 1, 9.5: "Full BASIC"

SET WINDOW -1.2, 1.2, -1.2, 1.2
FOR k = 0 TO 12
   SET COLOR MOD(k, 6) + 1
   LET t = k * 3.14159265 / 6
   PLOT LINES: 0, 0; COS(t), SIN(t)
NEXT k

エラーメッセージ

メッセージ原因
構文エラー (Syntax error)文の書き方が違います。
〜がありません (ブロックが閉じられていません)END IF、NEXT、LOOP、END SELECT、END SUB などの閉じ忘れ。
〜は定義されていませんCALL / 関数呼び出しの名前が見つかりません。
引数の数が合いませんSUB / FUNCTION の仮引数と実引数の数がちがう。
型が一致しません (Type mismatch)文字列と数を混ぜた(LET a = "x" など)。
添字が範囲外です (Subscript out of range)配列の範囲を超えた。
0で割りました (Division by zero)0 で割った。
不正な関数呼び出しですSQR(-1) や LOG(0) など、関数の範囲外。

制限事項

  • 規格にある MAT 文(行列演算)、PICTURE / DRAW、ファイル入出力、EXTYPE(例外処理)、文字列の SET TEXT 系の命令、OPTION ARITHMETIC DECIMAL などは未対応です。
  • 数値はすべて倍精度で計算します(規格の10進演算は行いません)。
  • 行番号は省略可能で(省略時は上から数えた番号が自動で付きます)、規格より緩くしています。変数は宣言なしで使え、未代入の数値は 0、文字列は空です。
  • グラフィックの窓は画面全体(正方形)に固定で、SET VIEWPORT は未対応です。
