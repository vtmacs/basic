SmileBASIC互換 マニュアル

ゲームを作りたくなる現代的なBASIC(SmileBASIC を参考にした非公式の互換実装)。行番号なし、ラベル、関数(DEF)、配列、スプライトとBG、VSYNC でのフレーム同期、RGB() での色指定、ファイル保存。

SmileBASIC互換 とは

SmileBASIC互換 は、株式会社スマイルブームの「SmileBASIC」を参考に、ゲームやグラフィックを手軽に作れることを目指した現代的なBASICです。行番号は使わず、飛び先には @LOOP のようなラベルを使い、DEF で関数を作り、配列は A[3] のように [ ] で書きます。このシミュレータは SmileBASIC の文法を参考に独自に作った非公式の互換実装で、株式会社スマイルブームとは関係がありません。

このシミュレータの SmileBASIC互換 は SmileBASIC の文法を参考にした非公式の再現です(標準のスプライト・タイルの絵や説明文はすべて独自のものです)。文字画面(コンソール)・図形・スプライト・BG・ファイル保存に対応しています。音楽・ネットワーク・実機の細かい仕様は含みません。

画面とはじめかた

  • グラフィック画面は 400 × 240 ドット(左上が (0,0))。その上に 50桁 × 30行の文字画面(コンソール)が重なります。
  • 実行は 「▶ 実行」(Ctrl+Enter)。ずっと動き続けるプログラムは「■ 停止」で止めます。
  • キー操作: ←↑↓→ が十字キー、ZXAS が A/B/X/Y ボタン、QW が L/R ボタン。画面をマウスでさわると TOUCH で座標が分かります。

プログラムの書き方

  • 行番号は使いません。1行に1つの文が基本で、: で区切れば複数書けます。
  • コメントは ' から行末まで(または REM)。? は PRINT の省略形です。
  • 飛び先のラベルは @名前。GOTO @LOOP、GOSUB @SUB1 のように使います。
  • 大文字・小文字は区別されません。文字列は "..."。
  • ブロックは IF … ENDIF、FOR … NEXT、WHILE … WEND、REPEAT … UNTIL、DEF … END など。

変数・配列・演算子

変数

変数名は英字で始まる英数字と _。名前の最後に $ を付けると文字列です。VAR で宣言できます(VAR A=3, B$="x")。宣言しなくても代入すれば使えます。数値は整数でも小数でも構いません(5/2 は 2.5)。

定数

#TRUE(1) #FALSE(0) #PI、色 #RED #GREEN #BLUE #YELLOW #CYAN #MAGENTA #WHITE #BLACK #GRAY #ORANGE #PURPLE #PINK #LIME #NAVY #MAROON #OLIVE #TEAL #SILVER、ボタン #UP #DOWN #LEFT #RIGHT #A #B #X #Y #L #R。

配列

DIM A[10] で要素数 10(A[0]〜A[9])。DIM B[3,4] は2次元。配列リテラル A=[3,1,2] でも作れます。LEN(A) で要素数。範囲外は「添字が範囲外です」エラー。文字列も A$[0] のように1文字を取り出せます。

DEF(関数・手続き)

  • DEF 名前(仮引数, …) … END で定義します。RETURN 値 で値を返し、RETURN だけなら値なしで戻ります。
  • 値を返す関数は式の中で 名前(引数)、値を返さない手続きは文として 名前 引数, … と呼び出せます(括弧は付けても構いません)。
  • DEF の中の変数はその DEF だけのもの(ローカル)です。外側(グローバル)で作った変数は読むことはできますが、代入すると DEF の中だけの新しい変数になります。外へ値を返したいときは RETURN を使います。
  • 配列は参照で渡されます(DEF の中で変更すると呼び出し元にも反映)。再帰呼び出しもできます。
DEF と配列シミュレータで試す ▶
DEF FACT(N)
  IF N<=1 THEN RETURN 1
  RETURN N*FACT(N-1)
END

DEF SHOW A
  VAR I
  FOR I=0 TO LEN(A)-1
    PRINT A[I];" ";
  NEXT
  PRINT
END

DIM A[5]
VAR I
FOR I=0 TO 4:A[I]=FACT(I+1):NEXT
SHOW A
PUSH A,720
PRINT "要素数=";LEN(A)
RSORT A
SHOW A

動かしてみよう(VSYNC・ボタン)

画面を1コマずつ描き直し、VSYNC で次のフレームまで待つのが、アニメーションとゲームの基本の形です。

ボールの動きシミュレータで試す ▶
' 実行すると跳ね続けます。←→キーで操作。「停止」で終了
VAR X=200,Y=40,VX=3,VY=0,B
WHILE 1
  B=BUTTON()
  IF B AND #LEFT THEN VX=VX-0.3
  IF B AND #RIGHT THEN VX=VX+0.3
  VY=VY+0.4
  X=X+VX:Y=Y+VY
  IF X<10 THEN X=10:VX=-VX
  IF X>390 THEN X=390:VX=-VX
  IF Y>225 THEN Y=225:VY=-VY*0.9
  GCLS RGB(0,0,50)
  GFILL 0,230,399,239,#GREEN
  GCIRCLE X,Y,10,#WHITE
  GPAINT X,Y,#RED
  LOCATE 0,0:PRINT "LEFT/RIGHT KEY"
  VSYNC 1
WEND
TOUCH で絵をかくシミュレータで試す ▶
' 画面をマウスでなぞって絵をかく
GCLS RGB(20,20,40)
VAR T,X,Y,PX,PY,C
PX=-1
WHILE 1
  TOUCH OUT T,X,Y
  IF T>0 THEN
    C=RGB(RND(256),RND(256),255)
    IF PX>=0 THEN GLINE PX,PY,X,Y,C
    PX=X:PY=Y
  ELSE
    PX=-1
  ENDIF
  VSYNC
WEND

スプライト

スプライトは、画面の上を自由に動かせる小さな絵(キャラクター)です。0〜511 の番号で管理し、位置・回転・拡大・色・当たり判定を持ちます。絵はグラフィックページ4から切り出して使います(グラフィックページを参照)。

最初から使える絵

何も用意しなくても、SPSET 番号, 定義番号 の「定義番号」に次の数を指定すれば使えます。定義番号 = 形の番号 × 4 + 色の番号(16×16ドット)です。

形 \ 色0 赤1 青2 緑3 黄
0 円0123
1 四角4567
2 ひし形891011
3 三角12131415
4 星16171819
5 ハート20212223
6 顔24252627
7 輪28293031

自分で絵をかくときは、ページ4に図形命令で絵を描いて SPDEF で範囲を登録します(下の例)。ページ4・5は 16×16 の升目に左上から順に番号が付き、番号 n の升目は u=(n MOD 32)*16, v=(n DIV 32)*16 の位置です。

SPANIM(自動アニメーション)

時間の単位はフレーム(1/60秒)。値を並べるごとに、その値まで時間をかけて変化します。最後に1つ数を付けるとくり返し回数(0 は無限)です。

対象並べる値(1組)意味
"XY"時間, x, y位置をなめらかに動かす
"R"時間, 角度回転
"S"時間, 横倍率, 縦倍率拡大・縮小
"C"時間, 色色の変化
"I"時間, 定義番号その時間だけ、その絵を表示(パラパラ漫画)

重ね順

奥から順に、グラフィック画面 → BG(3層→0層)→ スプライト(z が大きいものが奥)→ 文字画面です。当たり判定は回転を考えない四角形で行います。

スプライトで星あつめシミュレータで試す ▶
' ←→↑↓キーで顔を動かして、星を集めよう
VAR I,X=200,Y=120,B,SC=0
SPSET 0,27:SPHOME 0,8,8:SPOFS 0,X,Y
FOR I=1 TO 5
  SPSET I,16:SPHOME I,8,8
  SPOFS I,RND(380)+10,RND(220)+10
NEXT
WHILE 1
  B=BUTTON()
  IF B AND #LEFT THEN X=X-3
  IF B AND #RIGHT THEN X=X+3
  IF B AND #UP THEN Y=Y-3
  IF B AND #DOWN THEN Y=Y+3
  X=CLAMP(X,8,392):Y=CLAMP(Y,8,232)
  SPOFS 0,X,Y
  FOR I=1 TO 5
    IF SPHITSP(0,I) THEN
      INC SC
      SPOFS I,RND(380)+10,RND(220)+10
    ENDIF
  NEXT
  LOCATE 0,0:PRINT "SCORE ";SC
  VSYNC
WEND

' グラフィックページ4に絵をかき、SPDEF でスプライトにする
GPAGE 0,4
GFILL 0,128,15,143,RGB(255,200,0)

GFILL 10,132,12,135,#BLACK

GPAGE 0,0

  SPROT 0,MAINCNT*2
  VSYNC

BG(背景)

BG は、小さなタイル(16×16ドット)を升目に並べて作る背景です。0〜3 の4つの層があり、広い面をスクロールさせられます。タイルの絵はグラフィックページ5から取り、番号 n のタイルはスプライトと同じく左上から順に付きます。タイル番号 0 は透明です。

番号012345678910〜15
タイル透明ブロックれんが草地水砂石空黒市松赤・緑・青・黄・紫・水色の単色
命令書式説明
BGSCREENBGSCREEN 層, 横のマス数, 縦のマス数層の大きさを決めます(省略しても BGPUT したときに 64×64 で作られます)。
BGPUTBGPUT 層, x, y, タイル番号マス(x,y)にタイルを置きます。
BGFILLBGFILL 層, x1, y1, x2, y2, タイル番号範囲をタイルで埋めます。
BGGETBGGET(層, x, y)マスのタイル番号を返します。
BGOFSBGOFS 層, x, y / BGOFS 層 OUT x,yスクロール位置(ドット)。層の端までいくと反対側につながります。
BGSHOW / BGHIDEBGSHOW 層 BGHIDE 層層の表示・非表示。
BGCLRBGCLR [層]層を消します(省略すると全部)。

タイル番号に &H8000 を足すと左右反転、&H4000 を足すと上下反転します(BGPUT 0,3,5,2+&H8000)。

BG のスクロールシミュレータで試す ▶
' BG(背景のタイル)を3層に重ねてスクロールする(番号の小さい層が手前)
BGSCREEN 2,64,15
BGFILL 2,0,0,63,14,7
BGSCREEN 1,64,15
VAR I,X=0
FOR I=2 TO 60 STEP 9
  BGFILL 1,I,3,I+2,4,1
NEXT
BGSCREEN 0,64,15
BGFILL 0,0,13,63,14,3
FOR I=0 TO 62 STEP 5
  BGPUT 0,I,12,2
NEXT
SPSET 0,27:SPHOME 0,8,8:SPOFS 0,100,200
WHILE 1
  X=X+2
  BGOFS 0,X,0
  BGOFS 1,X/3,0
  VSYNC
WEND

グラフィックページ

グラフィックにはページがあります。ページ0は画面に表示される 400×240 の面、ページ1〜5 は 512×512 の作業用の面です。ページ4はスプライトの絵、ページ5はBGタイルの絵に使われます(最初から標準の絵が入っています)。

命令書式説明
GPAGEGPAGE 表示ページ[, 描画ページ]表示するページと、GPSET や GLINE などで描くページを決めます。(このシミュレータでは「表示, 描画」の順です。)
GCOPYGCOPY [元ページ,] x1,y1,x2,y2, dx,dy, モード描画ページの (dx,dy) へ四角形をコピー。モード 0 は透明部分をコピーしない、1 はそのままコピー。
GCLSGCLS描画ページを透明にします(ページ0は背景の黒が見えます)。GCLS 色 でその色に。
ACLSACLS画面・スプライト・BG・ページ4/5 を最初の状態に戻します。

透明な点(まだ何も描いていない点)は、スプライトやBGでは抜けて見えます。GPAGE 0,4 で描画先をページ4にして絵を描き、終わったら GPAGE 0,0 で戻すのが基本の流れです。

ファイル(SAVE / LOAD)

プログラムから、文字列や配列をファイルとして保存・読み込みできます。ファイルはお使いのブラウザの中(この サイト用の保存領域)に保存されるので、ページを閉じても、次に開いたときに残っています。別のパソコンや別のブラウザとは共有されません。

  • ファイル名は "TXT:名前"(文字列用)か "DAT:名前"(配列用)。名前は英数字と _ - . で32文字まで(大文字小文字は区別しません)。
  • 保存できる量はブラウザの制限(数MB)までです。
命令書式説明
SAVESAVE "TXT:名前", 文字列 / SAVE "DAT:名前", 配列保存します(同じ名前は上書き)。
LOADLOAD("TXT:名前") / LOAD "TXT:名前", 変数 / LOAD "DAT:名前", 配列変数読み込みます。関数の形(A$=LOAD("TXT:X"))でも使えます。
FILESFILES / FILES 文字列配列ファイルの一覧を表示(または配列に入れる)。
DELETEDELETE "TXT:名前"ファイルを消します。
RENAMERENAME "TXT:旧", "TXT:新"名前を変えます。

見つからないファイルを LOAD するとエラーになります。先に FILES で確かめるとよいでしょう。ブラウザの「サイトデータの削除」をすると、保存したファイルも消えます。

ハイスコアの保存シミュレータで試す ▶
' ブラウザに保存されるので、もう一度実行しても記録が残ります
VAR HI=0,N,I,FOUND=0
FILES F$
FOR I=0 TO LEN(F$)-1
  IF F$[I]=="TXT:HISCORE" THEN FOUND=1
NEXT
IF FOUND THEN HI=VAL(LOAD("TXT:HISCORE"))
PRINT "ハイスコア: ";HI
N=RND(1000)
PRINT "今回のスコア: ";N
IF N>HI THEN
  PRINT "新記録!"
  SAVE "TXT:HISCORE",STR$(N)
ENDIF
配列の保存シミュレータで試す ▶
' 配列を DAT ファイルに保存して読み戻す
DIM A[5]
VAR I
FOR I=0 TO 4:A[I]=I*I:NEXT
SAVE "DAT:SQUARES",A
DIM B[1]
LOAD "DAT:SQUARES",B
PRINT LEN(B);" 個: ";B[0];B[1];B[2];B[3];B[4]
DELETE "DAT:SQUARES"

制限事項

  • 未対応: 音楽(BGMPLAY)・効果音の細かい制御、BGのアニメーション/回転/拡大(BGANIM など)、スプライトの連結(SPLINK)、SPFUNC、回転を考えた当たり判定、スプライトの左右反転属性(かわりに SPSCALE の負の値を使います)、GSAVE/GLOAD や PRG・GRP のファイル、OUT 引数つきの DEF、マルチタスク、KEYBOARD。
  • スプライトは最大 512 個、BG は 4 層(最大 256×256 マス)、グラフィックページは 6 枚です。描画は最近傍(ドットのまま拡大)です。
  • COLOR の16色パレットは本シミュレータのものです(実機とは色が少し違います)。RGB() は 24 ビットの色を返します(透明度は使いません)。
  • BUTTON() の割り当て・STICK の値はキーボード用の簡易的なものです。
  • 標準のスプライト/タイルの絵は、このシミュレータ独自のものです。
  • 関数(式の中で呼ぶ DEF)の中では INPUT や VSYNC のように「待つ」命令は使えません(手続きとして呼ぶ DEF の中なら使えます)。
  • 文字は 8×8 ドット相当の升目に描かれ、フォントは実機と異なります。
