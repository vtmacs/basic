方言の比較

Tiny BASIC・N88-BASIC・Full BASIC・smile BASIC の違いを、一覧表と「同じプログラムを4つの方言で書いた例」で比べます。

Tiny BASIC

最小のBASIC。行番号・整数・IF/GOTO/GOSUB。「プログラムとは何か」を学ぶ入口。

N88-BASIC

行番号つきの定番BASIC。色・図形・音・文字列がそろったレトロPCの味。

Full BASIC

規格化された構造化BASIC。行番号なし、SUB/FUNCTION、数学向きの図形。

smile BASIC

ゲーム向けの現代的BASIC。ラベル・DEF・配列・VSYNC・RGB。
表の印: ● 使える　△ 一部だけ(拡張や制限つき)　× 使えない。印のない欄は書き方の違いです。このシミュレータが再現している範囲での比較です。

2. 同じことを4つの方言で書く

それぞれの「シミュレータで試す」を押すと、その方言のシミュレータにプログラムが入った状態で開きます。

1 から 10 の合計

Tiny BASIC

1 から 10 の合計シミュレータで試す ▶
10 LET S=0
20 LET I=1
30 LET S=S+I
40 LET I=I+1
50 IF I<=10 THEN GOTO 30
60 PRINT S
70 END

N88-BASIC

1 から 10 の合計シミュレータで試す ▶
10 S=0
20 FOR I=1 TO 10
30   S=S+I
40 NEXT I
50 PRINT S

Full BASIC

1 から 10 の合計シミュレータで試す ▶
LET s = 0
FOR i = 1 TO 10
   LET s = s + i
NEXT i
PRINT s
END

smile BASIC

1 から 10 の合計シミュレータで試す ▶
S=0
FOR I=1 TO 10
  S=S+I
NEXT
PRINT S

偶数か奇数か

Tiny BASIC

偶数か奇数かシミュレータで試す ▶
10 LET N=7
20 IF N-N/2*2=0 THEN PRINT "偶数"
30 IF N-N/2*2<>0 THEN PRINT "奇数"
40 END

N88-BASIC

偶数か奇数かシミュレータで試す ▶
10 N=7
20 IF N MOD 2=0 THEN PRINT "偶数" ELSE PRINT "奇数"

Full BASIC

偶数か奇数かシミュレータで試す ▶
LET n = 7
IF MOD(n, 2) = 0 THEN
   PRINT "偶数"
ELSE
   PRINT "奇数"
END IF
END

smile BASIC

偶数か奇数かシミュレータで試す ▶
N=7
IF N MOD 2==0 THEN
  PRINT "偶数"
ELSE
  PRINT "奇数"
ENDIF

九九の表(3の段まで)

Tiny BASIC

九九の表(3の段まで)シミュレータで試す ▶
10 LET A=1
20 LET B=1
30 PRINT A*B;" ";
40 LET B=B+1
50 IF B<=9 THEN GOTO 30
60 PRINT
70 LET A=A+1
80 IF A<=3 THEN GOTO 20
90 END

N88-BASIC

九九の表(3の段まで)シミュレータで試す ▶
10 FOR A=1 TO 3
20   FOR B=1 TO 9
30     PRINT USING "###";A*B;
40   NEXT B
50   PRINT
60 NEXT A

Full BASIC

九九の表(3の段まで)シミュレータで試す ▶
FOR a = 1 TO 3
   FOR b = 1 TO 9
      PRINT USING "###": a * b;
   NEXT b
   PRINT
NEXT a
END

smile BASIC

九九の表(3の段まで)シミュレータで試す ▶
FOR A=1 TO 3
  FOR B=1 TO 9
    PRINT FORMAT$("%3d",A*B);
  NEXT
  PRINT
NEXT

2乗する(サブルーチン/関数)

Tiny BASIC

2乗する(サブルーチン/関数)シミュレータで試す ▶

20 GOSUB 100
30 PRINT R
40 END
100 LET R=N*N
110 RETURN

END

  RETURN X*X

配列の合計

Tiny BASIC

配列の合計シミュレータで試す ▶
10 LET @(0)=3
20 LET @(1)=5
30 LET @(2)=7
40 LET S=0
50 LET I=0
60 LET S=S+@(I)
70 LET I=I+1
80 IF I<3 THEN GOTO 60
90 PRINT S
100 END

N88-BASIC

配列の合計シミュレータで試す ▶
10 DIM A(2)
20 A(0)=3: A(1)=5: A(2)=7
30 FOR I=0 TO 2: S=S+A(I): NEXT
40 PRINT S

Full BASIC

配列の合計シミュレータで試す ▶
DIM a(2)
LET a(0) = 3
LET a(1) = 5
LET a(2) = 7
FOR i = 0 TO 2
   LET s = s + a(i)
NEXT i
PRINT s
END

smile BASIC

配列の合計シミュレータで試す ▶
DIM A[3]
A[0]=3:A[1]=5:A[2]=7
FOR I=0 TO 2:S=S+A[I]:NEXT
PRINT S

3. 方言をまたいで書き換えるときのポイント

ポイント内容
行番号 ⇔ ラベルN88-BASIC の GOTO 100 は、smile BASIC では GOTO @LABEL(@LABEL を飛び先の行に書く)にします。Full BASIC は行番号を省略して構造化(DO / IF ブロック)で書き換えるのがおすすめです。
真偽の値N88-BASIC の「真」は -1、他は 1。IF A THEN のように 0 かどうかだけを見る使い方は共通ですが、X = (A>B) のように値を取り出すと結果が変わります。
乱数N88-BASIC の INT(RND(1)*6)+1 は、smile BASIC では RND(6)+1、Tiny BASIC では RND(6) です。
文字の位置MID$ の位置は N88-BASIC / Full BASIC が 1 から、smile BASIC が 0 から。INSTR が「見つからない」ときは N88 が 0、smile が -1 です。
配列の大きさDIM A(10) は N88-BASIC / Full BASIC で 11 個(0〜10)、DIM A[10] は smile BASIC で 10 個(0〜9)。
数の表示N88-BASIC と Full BASIC の PRINT は数の前後に空白を入れます(PRINT 5 は 5 )。見た目をそろえたいときは STR$ と MID$ を使うか、PRINT USING を使いましょう。
グラフィックの座標Full BASIC だけは「好きな座標系」(数学と同じで上が +y)で描きます。ほかは左上が (0,0) のドット座標です。
色Tiny / N88 / Full は 0〜7 の色番号(Full は色名も)、smile BASIC は RGB(r,g,b) か #RED などの定数です。

4. どれを選ぶ?

  • プログラムの動く仕組みを最小の道具で学びたい → Tiny BASIC
  • 昔のパソコンの雰囲気で、色や図形や音を楽しみたい → N88-BASIC
  • きれいな構造のプログラムや、数学・理科のグラフを描きたい → Full BASIC
  • ゲームやアニメーションを作りたい → smile BASIC
