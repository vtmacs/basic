Tiny BASIC とは

Tiny BASIC は、まだパソコンのメモリが 4KB 前後しかなかった 1975 年ごろ、「小さなマイコンでも動くBASIC」として考えられた言語です。多くの処理系が作られ、その後の N88互換BASIC などパソコン用BASICの先祖にあたります。

機能をぎりぎりまで削っているので、FOR も、文字列変数も、小数もありません。そのかわり、覚えることが少なく、「プログラムは上から順に実行され、IF と GOTO で流れが変わる」という基本がそのまま見えます。

Tiny BASIC は実装ごとに細部が違います。このシミュレータは、よく知られた Tiny BASIC の文法(PRINT / IF / GOTO / GOSUB / RETURN / INPUT / LET / END / REM / RND)に、描画用の拡張命令を加えたものです。

画面とはじめかた

  • 画面は緑色の文字画面(80桁 × 25行)と、重ねて表示される 640 × 400 ドット のグラフィック面です。
  • 左のエディタにプログラムを書き、「▶ 実行」(Ctrl+Enter)で実行します。
  • INPUT で入力待ちになると、画面の下に入力欄が出ます。入力して Enter を押してください。
  • 行番号のない行があると、「行番号がありません」というエラーになります。「行番号をふる」ボタンで10ずつ自動で付けられます。
Hello, Worldシミュレータで試す ▶
10 REM はじめてのTiny BASIC
20 PRINT "Hello, World!"
30 END

プログラムの書き方

  • すべての行は 行番号(正の整数)で始めます。実行は行番号の小さい順です。入力順は関係ありません。
  • 同じ行番号を2回書いたときは、あとの行が有効になります。20 のように番号だけの行は、その行の削除を意味します。
  • 1行に書ける文は1つだけです(: で区切って複数の文を書くことはできません)。
  • 大文字・小文字は区別されません。
  • プログラムの最後は END を書くか、最終行まで実行すると終了します。
  • 文字列("...")は PRINT と INPUT のメッセージとして使います。
入力の順序と実行の順序シミュレータで試す ▶
10 REM 行番号は飛び飛びに付けると、あとで間に追加できる
20 PRINT "B"
10 PRINT "A"
30 END

変数・数・演算子

変数

変数名は A〜Z の1文字だけ(26個)。値は整数(-32767〜32767)です。文字列変数・小数はありません。

配列は @(0)〜@(1023) の1本だけ(@(I) のように添字に式が書けます)。

種類例説明
数の定数0 123 -5整数のみ
変数A X ZA〜Z の1文字
配列@(1) @(I+1)共通の1次元配列(0〜1023)

演算子

演算子意味例
+ - * /足し算・引き算・かけ算・割り算(小数点以下は切り捨て)7/2 → 3、-7/2 → -3
( )計算の順序を決める(2+3)*4 → 20
= <> >< < > <= >=比較(IF の条件に使う)。真は 1、偽は 0A<>B

計算結果が -32767〜32767 を超えると「オーバーフロー」エラーになります(昔の16ビット整数と同じです)。

整数の計算シミュレータで試す ▶
10 PRINT 7/2;" ";-7/2;" ";2+3*4;" ";(2+3)*4
20 PRINT 100/7*7
30 END

命令リファレンス

命令書式説明
REMREM コメント注釈。実行されません。
LETLET 変数 = 式変数に値を入れます。LET は省略できます(A=5)。
PRINTPRINT 項目 [; または , 項目 ...]画面に表示します。項目は式か "文字列"。くわしくは下の説明。
INPUTINPUT 変数 [, 変数 ...]キーボードから数を入力します。複数のときは 3,4 のようにカンマで区切って入力。数以外を入れると「再入力」になります。
IFIF 式 比較 式 THEN 文条件が成り立つときだけ、THEN の後ろの文を実行します。THEN の後に行番号を書くと GOTO と同じ意味になります(IF A=1 THEN 100)。
GOTOGOTO 式指定の行へ飛びます。行番号は式でも構いません(GOTO A*100)。
GOSUBGOSUB 式サブルーチン(指定の行から RETURN まで)を呼び出します。
RETURNRETURNGOSUB の次の文へもどります。
ENDENDプログラムを終了します。
STOPSTOPプログラムを止めます。
CLEARCLEARすべての変数と配列を 0 にします。

PRINT の書き方

  • ; で区切ると、すき間なく続けて表示します。, で区切ると、次の 8 桁ごとの位置に揃えます。
  • 行末に ; や , を付けると、改行しません。
  • 数は余計な空白なしで表示されます(PRINT 5 → 5)。
  • 何も書かない PRINT は改行だけを行います。
PRINT の区切りシミュレータで試す ▶
10 PRINT "A=";5;" B=";6
20 PRINT 1,2,3
30 PRINT "AB";
40 PRINT "CD"
50 END

グラフィック(このシミュレータの拡張)

本来の Tiny BASIC にはグラフィックの命令はありません。このシミュレータでは、「できる限り描ける」ように、次の拡張命令を用意しています。座標は 左上が (0,0)、右へ x、下へ y が増え、画面は 640 × 400 ドットです。

命令書式説明
CLSCLS文字画面とグラフィック画面を消去します。
COLORCOLOR n文字と図形の色を決めます(下の色表)。
PLOTPLOT x,y点を1つ打ちます。
LINELINE x1,y1,x2,y2線を引きます。
CIRCLECIRCLE x,y,r中心 (x,y)、半径 r の円をかきます。
WAITWAIT nn × 0.01 秒 待ちます(アニメーション用)。
n01234567
色黒青赤紫緑水色黄白
線と円シミュレータで試す ▶
10 REM 線で曲線のように見せる(ストリングアート)
20 CLS
30 LET I=0
40 COLOR 6
50 LINE 0,I,I,399
60 LET I=I+20
70 IF I<=400 THEN GOTO 50
80 COLOR 2
90 CIRCLE 320,200,120
100 END

80 END

エラーメッセージ

メッセージ原因と対処
行番号がありませんすべての行の先頭に行番号が必要です。「行番号をふる」を使うと便利です。
Tiny BASICの変数名は A〜Z の1文字ですAB や SUM は使えません。1文字の変数にします。
〜は N88互換BASIC・… のコマンドですFOR、WHILE、DIM などは Tiny BASIC にはありません。IF と GOTO で書き換えます。
オーバーフロー (Overflow)計算結果が -32767〜32767 を超えました。
0で割りました (Division by zero)0 で割っています。
未定義の行番号ですGOTO / GOSUB で存在しない行を指定しています。
RETURN に対応する GOSUB がありませんGOSUB を通らずに RETURN を実行しました。END を忘れていないか確認してください。
再入力してください (Redo from start)INPUT に数でないものを入力した場合のメッセージです(エラーではなく再入力になります)。

制限事項・他の方言との違い

  • FOR / NEXT、文字列変数、小数、ELSE、論理演算(AND / OR)、SIN などの数学関数はありません。
  • 複数文を : で区切って書くことはできません。
  • 整数は -32767〜32767 の範囲です。
  • PLOT / LINE / CIRCLE / COLOR / CLS / WAIT はこのシミュレータの拡張で、実機の Tiny BASIC にはありません。

各BASICの違いは 方言の比較 にまとめています。もっと機能がほしくなったら N88互換BASIC や Full BASIC へ進みましょう。
